# 海洛易 (HailuoYi)

异环二创模拟股票交易平台 —— 在虚构的经济体系中，体验真实的投资博弈。

## 项目简介

海洛易 是一个专为 异环玩家打造的模拟股票交易平台。在这里，你可以：

- 买卖虚拟股票，体验真实市场波动
- 运用策略，在虚拟经济中积累财富

本项目完全开源，遵循 GPL-3.0 许可证，欢迎社区贡献与二次创作。


## 功能特性

- 虚拟股票交易系统（买入/卖出/撤单）
- 实时行情模拟与K线图表
- 用户资产管理看板


## 技术栈

极度先进的HTML纯前端实现
